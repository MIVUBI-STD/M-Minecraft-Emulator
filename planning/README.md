# Planning

This directory records **current or future work intent**, not stable architecture or runtime proof.

- `development.md` — one canonical emulator development continuation.
- `operations.md` — setup, support, release operations only when activated.
- `projects.md` — scoped secondary deliverables only when they exist.

Update the relevant file at a meaningful milestone, not every small investigative step. Current GitHub source and actual verification results outrank older continuation text.
